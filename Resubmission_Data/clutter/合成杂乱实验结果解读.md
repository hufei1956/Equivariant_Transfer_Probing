# 合成杂乱背景实验：结果与对论文结论的影响

## 实验设计

- 用 DINO+SAM 把每张 TrashNet 图片里的物体抠出来，贴到三种背景上。同一张图片在三种背景下，物体的位置和大小完全相同，只有背景不同。
  - **plain（对照）**：纯色背景。
  - **rand（随机杂乱）**：Places365 场景图，背景与类别无关。
  - **corr（相关杂乱）**：80% 的概率使用该类别对应的场景组，人为制造"背景→类别"的捷径。
- 另有一个只用于测试的 **conf（冲突）** 版本：背景来自其他类别的场景组。
- 训练规模：3 种背景 × 3 个探针（R18、C8、D4）× 5 个种子，共 45 个模型，全部完成，无失败。
- 训练设置与主实验完全一致。

## 主要结果

以下数值均为均值 ± 95% CI，n = 5；"均衡准确率"指 RealWaste 类别均衡目标集上的准确率。

| 探针 | 背景 | TN 同背景准确率 | TN 冲突背景准确率 | RW 均衡准确率 | RW 注意力增益 ΔAC |
|---|---|---|---|---|---|
| ResNet-18 | plain | 75.1 | 35.0 | 32.9 ± 1.6 | +0.093 |
| ResNet-18 | rand | 49.3 | 49.0 | 25.0 ± 6.4 | **+0.018（≈随机）** |
| ResNet-18 | corr | 55.9 | 41.3 | 27.3 ± 1.3 | **+0.028（≈随机）** |
| D4 | plain | 80.0 | 38.2 | 34.4 ± 3.9 | +0.100 |
| D4 | rand | 59.3 | 58.5 | 32.6 ± 4.0 | **+0.104（不变）** |
| D4 | corr | 62.9 | 48.1 | 28.1 ± 3.3 | +0.090 |

C8 的结果介于 ResNet-18 和 D4 之间，详见 Excel。

### 1. 纯度部分：得到干预证据（成立）

- 源域加入杂乱背景后，ResNet-18 迁移到 RealWaste 的表现下降：
  - 随机杂乱：均衡准确率 −7.9（p = 0.049），mAP −5.4（p = 0.048）。
  - 相关杂乱：均衡准确率 −5.6（p = 0.002），mAP −2.2（p = 0.041）。
- ResNet-18 对 RealWaste 物体的注意力降到随机水平（+0.093 → +0.018 / +0.028）。这与真实 RealWaste 训练模型在 TrashNet 上"注意力处于随机水平"的现象一致。
- 用相关杂乱训练的模型确实学会了背景捷径：换成冲突背景后，准确率下降 13–15 个百分点。三个探针都是如此，全部 p ≤ 0.002。
- **需要如实说明：** ResNet-18 准确率下降的一部分，来自它对杂乱源域本身拟合变差（域内准确率从 75% 降到 49–56%）。按域内准确率归一化后，它的迁移比例并没有下降。所以注意力是更直接的证据。

### 2. 先验补偿部分：对"与类别无关的杂乱"成立

- **D4 相对 ResNet-18 的优势扩大：** 背景为 plain 时，D4 与 ResNet-18 几乎持平（+1.5，不显著）。换成随机杂乱后，差距扩大到 +7.6（p = 0.004）。
  - 交互效应（差中差）：均衡准确率 +6.1（p = 0.036）；全部目标图片上 +7.2（p = 0.015）。
  - C8 的交互效应：均衡准确率 +5.9（p = 0.055）；全部目标图片上 +9.4（p = 0.014）。
- **D4 的注意力不受杂乱影响：** 三种背景下分别为 +0.100 / +0.104 / +0.090。它相对 ResNet-18 的注意力优势扩大 +0.078 和 +0.055（p = 0.042 和 0.039）。
- **注意力保护程度呈梯度：** ResNet-18 下降最多，C8 居中，D4 基本不降。
- 这等于用干预实验复现了主实验中"等变收益只出现在杂乱源域方向"的现象。
- **需要如实说明：** D4 在随机杂乱下的优势，有一部分来自它更好地拟合了杂乱源域（域内 59% 对 49%）。按域内准确率归一化后，交互效应只是边缘显著（p = 0.06）。

### 3. 边界条件：对"与类别相关的背景捷径"不成立（事先预判过的可能结果）

- D4 与 ResNet-18 的捷径指数几乎相同：14.8 对 14.7，差值 +0.1，p = 0.96。
- 在相关杂乱条件下，D4 的迁移优势没有扩大（交互 −0.8，不显著）。
- 解释：旋转和反射约束限制的是特征随方向变化的方式，挡不住一个能直接预测标签的背景统计量。
- 这一点作为假说的**边界条件**写进论文，反而让结论更可信：几何先验能对付"噪声式杂乱"，但对付不了"虚假相关"；后者只能靠清理训练数据来解决。

## 对论文结论的影响

| 原结论 | 修改后 |
|---|---|
| Feature Purity Hypothesis 只有 Grad-CAM 相关性证据 | **两部分假说**：纯度部分有干预支持；先验补偿部分对类别无关杂乱成立，并明确了边界条件 |
| "干净源域更好"是核心发现 | 保留，但降级为数据集特定观察（其中很大一部分来自目标域类别构成） |
| GTA/GPI 以 C4 为基线 | 删除 GPI；GTA 改为相对 ResNet-18 的种子内配对增益；新核心发现为"等变收益有方向性" |
| 因果需要未来工作来验证 | 合成干预已完成；未来工作改为"用真实设施背景重复干预、跨更多数据集验证" |

**总体评价：** 论文的证据链现在比较完整：观察到的现象 → 排除数据增强和模型容量的解释 → 相关性证据（随机样本 Grad-CAM）→ 干预证据 → 边界条件。在 IEEE Access 的标准下，这是扎实的完整工作。

它仍然只用了一对数据集、5 个种子，背景也是合成的。我们在文中把结论限定为"机制可以起作用"，没有写成"机制定量解释了 TN/RW 的不对称"。
